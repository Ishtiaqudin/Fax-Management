# Fax Management System

A simple and organized system to manage fax sending, receiving, tracking, and records — all in one place.

> **Status:** 🚧 In Development — Initial setup
> This repository was created on 15 October 2026 and is currently in its starting phase. Features and documentation will be updated as the project develops.

---

## 📌 Overview

Managing faxes manually leads to lost documents, no delivery confirmation, and no proper history. 

**Fax-Management** is being built to solve that — a central place to:

- Send and receive faxes
- Track delivery status in real time
- Maintain a complete history / register of all faxes
- Manage contacts and fax numbers easily

This project is developed by **Ishtiaq Uddin**, an accountant and developer based in the UAE, as part of his work on practical office management tools.

---

## ✨ Planned Features

- [ ] Send a fax with recipient name, number, and document
- [ ] Receive and store incoming faxes
- [ ] Fax history / register with date, sender, receiver, and status
- [ ] Delivery status tracking — Sent / Delivered / Failed / Pending
- [ ] Contacts book for frequently used fax numbers
- [ ] Search and filter fax history by date, name, or status
- [ ] Export records (PDF / Excel) for office use
- [ ] User login and secure access
